# Kai Khalid

I build AI tools that people can trust with real work, in Nairobi, Kenya.

My focus is the unglamorous part of applied AI: grounding answers in real sources, testing whether they are right, and keeping a human in the loop where decisions matter.

### What I work on
- **Grounded AI assistants:** retrieval-augmented assistants that cite their sources, route questions to the right place, and say "I don't know" when they should.
- **Evaluation:** golden test sets, LLM-as-judge grading against reference answers, retrieval recall checks and regression baselines, so quality is measured rather than assumed.
- **Human-in-the-loop systems:** agent workflows where AI drafts and a person approves, with an audit trail of who did what.
- **Data that holds up:** clean pipelines, privacy by design and tenant isolation.

### Public projects
- [brandcal](https://github.com/Kaikhalid/brandcal): a CLI and SQLite toolkit for AI agents that run a human-approved content calendar, with a hash-chained audit log.
- [spec-and-build-skill](https://github.com/Kaikhalid/spec-and-build-skill): a skill for AI coding agents that separates planning from building and writes code only after approval.
- [cookie-consent](https://github.com/Kaikhalid/cookie-consent): a config-driven cookie banner that is actually Google Consent Mode v2 compliant.
